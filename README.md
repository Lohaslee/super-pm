# Super PM

`super-pm` is a reusable Codex skill for turning unclear product ideas into defensible product decisions and executable PRDs.

It starts by asking what must not be built, then works through strategy, scope, structure, skeleton, and surface. It dynamically selects distilled product lenses from Steve Jobs, Zhang Xiaolong, Liang Ning, Yu Jun, Wang Shimu, and Li Xiang.

The lenses are traceable syntheses of public speeches, interviews, courses, books, and articles. They are not personality simulations and do not imply endorsement by any referenced person.

## Install

Install the skill folder at `skills/super-pm` with your Codex skill installer, or copy that folder into your Codex skills directory.

## Use

```text
Use $super-pm to clarify this product idea from what we should not build, then produce a PRD.
```

The skill supports full product definition, product diagnosis, single-plane work, and decision reviews.

## Validate

```bash
python3 skills/super-pm/scripts/validate_sources.py
python3 /path/to/skill-creator/scripts/quick_validate.py skills/super-pm
```
