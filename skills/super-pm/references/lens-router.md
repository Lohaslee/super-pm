# Product-Lens Router

Select lenses by decision type. Use two to four lenses; add another only when it introduces a genuinely different test.

| Lens | Strongest use | Typical planes | Route when the question involves |
|---|---|---|---|
| Steve Jobs | Focus and end-to-end product coherence | Strategy, Scope, Framework, Surface | ruthless subtraction, integrated experience, product quality, clear product story |
| Zhang Xiaolong | Human motivation and restrained interaction | Strategy, Scope, Structure, Framework, Surface | social behavior, attention, messaging, tools, notifications, natural interaction |
| Liang Ning | Emotion, opportunity, and product character | Strategy, Scope, Surface | pain/pleasure/fear, user state, market opening, product temperament |
| Yu Jun | User value and transaction analysis | Strategy, Scope | value exchange, switching cost, incentives, stakeholders, product-manager judgment |
| Wang Shimu | Breakthrough-product discovery and execution | Strategy, Scope, Structure, Framework | market structure, user research, product evolution, team decisions, content/community products |
| Li Xiang | Product definition and organizational delivery | Strategy, Scope | target definition, business loop, technology choice, organization, scale and execution |

## Default Routes

- **Unclear 0-to-1 idea**: Liang Ning + Yu Jun + Li Xiang; add Jobs when focus is weak.
- **Feature request overload**: Jobs + Yu Jun + Zhang Xiaolong.
- **Social or community product**: Zhang Xiaolong + Wang Shimu + Yu Jun.
- **Content product**: Wang Shimu + Liang Ning + Zhang Xiaolong.
- **Complex physical/software product**: Li Xiang + Jobs + Yu Jun.
- **Interaction or navigation problem**: Zhang Xiaolong + Wang Shimu; add Jobs for end-to-end coherence.
- **Visual or product-character problem**: Jobs + Liang Ning; add Zhang Xiaolong when restraint and attention matter.
- **Growth-versus-experience conflict**: Zhang Xiaolong + Yu Jun + Li Xiang.

## Routing Test

Before loading a thinker reference, complete this sentence:

`This lens can change the decision by testing ______.`

If the blank cannot be filled concretely, do not load that lens.
